Agent Feedback Loop
Per-Step Loop
01Screenshot captured by Playwright → JPEG compressed
02OpenCV detects buttons, inputs, colored CTAs
03Gemini Vision analyses screen with full TaskMemory context injected
04Vision Grounding cross-references CV + Gemini elements by IoU overlap
05Gemini generates action with target, reason, confidence, grounding_source
06ValidatedAction.from_raw() — schema enforced, malformed rejected
07If confidence < 0.70 or irreversible → pause, send confirm_required event
08Playwright executes validated action in real Chromium browser
09TaskMemory updated: step record, observation, grounding hits
10WS broadcasts screenshot + explainable action + memory summary to UI
Self-Healing Recovery
—Action fails: element not found or timeout
①Scroll down — broadcasts "The {target} was not visible. Scrolling the page to find it."
②Text-similarity search (token overlap) across all CV + Gemini elements. If found: "The button moved. Located via text similarity (80%) at (72%, 82%)."
②bNo match → scroll up to search full page
③Ask user — emits healing_failed WS event. "Could not locate '{target}' after 2 attempts."
④Gemini deep recovery — fresh screenshot + full re-analysis + diagnosis
⑤Execute recovery action or abort if Gemini recommends it
